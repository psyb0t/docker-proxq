# Go code

Prefix: GO. Applies to every `.go` file outside `vendor/`.

- **GO1:** `make lint` must pass. It runs `go fix -diff` and golangci-lint with `.golangci.yml`, which enables almost every linter, an 80-column `lll` limit and `wsl_v5`. Fix the code rather than adding a `//nolint`; when one is unavoidable, name the linter (`//nolint:lll`), as the struct tags in `internal/config/config.go` do.
- **GO2:** Wrap returned errors with `ctxerrors.Wrap` or `Wrapf` and a short action phrase (`"parse config yaml"`, `"enqueue task"`). Sentinels live in an `errors.go` next to the code that returns them (`internal/config/errors.go`, `pkg/clients/openai/errors.go`). Reuse a `common-go/errors` sentinel when one fits, as `validate` does with `ErrRequiredFieldNotSet`.
- **GO3:** New imports must pass the `depguard` allow list in `.golangci.yml`. Adding a dependency means extending that list, then `make dep` to update `go.mod`, `go.sum` and `vendor/`.
- **GO4:** Log through common-go `slogging.GetLogger(r.Context())` or `slogging.GetLogger(ctx)`, which uses a logger stored in the context and falls back to `slog.Default()`, as the handlers in `internal/proxy` do.
- **GO5:** Header names shared with clients are constants in `pkg/types/headers.go`. `internal/proxy/job.go` re-exports them; do not spell them as string literals elsewhere.
- **GO6:** Do not hand-edit `vendor/`. It is regenerated by `make dep`.
